# Hidden Renda

Crie uma LANDING PAGE DE ALTA CONVERSÃO para o produto digital “RENDA OCULTA”.

IMPORTANTE:

Use a imagem da capa do ebook anexada neste projeto como o principal mockup visual do produto. NÃO recrie a capa, NÃO altere sua identidade visual e NÃO substitua por uma imagem genérica.

==================================================

IDENTIDADE VISUAL

==================================================

A identidade visual deve seguir rigorosamente a capa do ebook:

- Fundo predominantemente preto (#050505 / #080808)

- Verde neon como cor de destaque (#39FF14 / #00E63A)

- Branco/off-white para textos principais

- Estética tecnológica, misteriosa, premium e cinematográfica

- Glow verde suave

- Partículas luminosas

- Pequenos efeitos de energia/luz

- Glassmorphism muito discreto

- Bordas finas em verde

- Sombras profundas

- Contraste alto

- Tipografia moderna, forte e condensada nos títulos

- Corpo de texto limpo e altamente legível

NÃO deixar a página poluída.

NÃO usar excesso de cards.

NÃO usar visual de página de curso tradicional.

NÃO usar azul, roxo, laranja ou outras cores que quebrem a identidade.

A sensação deve ser:

“Existe uma oportunidade que poucas pessoas conhecem.”

==================================================

ESTRUTURA DA LANDING PAGE

==================================================

1. HERO / PRIMEIRA DOBRA

Criar uma hero section extremamente impactante.

Pequeno selo acima do título:

“DESCUBRA UMA NOVA POSSIBILIDADE DE RENDA”

Título principal:

“DESCUBRA O MÉTODO PARA GANHAR ATÉ R$5.000/MÊS PELO CELULAR”

Dar enorme destaque visual para:

“ATÉ R$5.000/MÊS”

Subheadline:

“Aprenda formas práticas de criar uma renda extra usando apenas o seu celular, trabalhando de casa e começando do zero.”

Adicionar CTA principal:

“QUERO DESCOBRIR O MÉTODO”

Adicionar pequeno texto abaixo do botão:

“Comece hoje pelo celular.”

Ao lado do texto, mostrar a CAPA DO EBOOK ANEXADA, em mockup 3D premium, com leve inclinação e sombra/glow verde.

Adicionar partículas verdes e um brilho muito sutil atrás do ebook.

O hero deve transmitir imediatamente:

RENDA + CELULAR + OPORTUNIDADE + MISTÉRIO.

==================================================

2. BLOCO DE CURIOSIDADE

==================================================

Título:

“E SE O SEU CELULAR PUDESSE SER MAIS DO QUE UMA FERRAMENTA?”

Texto:

“Todos os dias, milhões de pessoas passam horas no celular. Poucas sabem transformar esse tempo em oportunidades reais de renda extra.”

Criar uma pequena animação de brilho passando lentamente pelo fundo.

Destacar visualmente:

“Seu celular já está nas suas mãos.

Agora falta descobrir como usá-lo de forma estratégica.”

==================================================

3. O QUE VOCÊ VAI DESCOBRIR

==================================================

Título:

“O QUE EXISTE DENTRO DO RENDA OCULTA?”

Criar 4 cards minimalistas:

📱 “Oportunidades pelo celular”

“Descubra diferentes formas de buscar uma renda extra usando seu próprio celular.”

⚡ “Estratégias simples”

“Conteúdo direto, sem excesso de teoria e pensado para quem está começando.”

🏠 “Trabalhe de onde estiver”

“Aprenda possibilidades que podem ser exploradas de casa e no seu tempo livre.”

🚀 “Comece do zero”

“Não é necessário ser especialista para começar a entender o método.”

Cards com fundo preto, bordas verdes extremamente sutis e glow apenas ao passar o mouse.

==================================================

4. SEÇÃO DE TRANSFORMAÇÃO

==================================================

Criar uma seção visualmente forte.

Título:

“VOCÊ NÃO PRECISA DE MAIS UM MOTIVO PARA ESPERAR.”

Texto:

“Você já tem uma ferramenta poderosa nas mãos. O próximo passo é aprender a enxergar as oportunidades que podem existir por trás dela.”

Mostrar novamente pequenos elementos gráficos inspirados na capa:

- celular

- símbolo $

- partículas verdes

- linhas digitais

- notificações abstratas

Não exagerar.

CTA:

“QUERO COMEÇAR AGORA”

==================================================

5. OFERTA BLACK

==================================================

Criar uma seção visualmente mais intensa, inspirada em uma oferta Black Friday premium.

Fundo preto quase absoluto com glow verde.

Badge:

“OFERTA ESPECIAL”

Título:

“DESBLOQUEIE O RENDA OCULTA”

Mostrar o mockup do ebook.

Criar lista:

✓ Acesso ao conteúdo completo

✓ Estratégias para buscar renda extra pelo celular

✓ Conteúdo direto e prático

✓ Acesso imediato após a compra

CTA grande:

“QUERO ACESSAR O RENDA OCULTA”

Adicionar abaixo:

“Pagamento seguro • Acesso digital”

IMPORTANTE:

Não inventar preço.

Não inventar desconto.

Não criar contador falso.

Não criar escassez falsa.

Todos os botões de CTA devem direcionar para o checkout Kiwify fornecido no briefing.

==================================================

6. DEPOIMENTOS / AVALIAÇÕES

==================================================

Criar uma seção:

“QUEM JÁ COMEÇOU A BUSCAR UMA NOVA RENDA”

Criar 3 cards de depoimentos.

IMPORTANTE:

Não inventar depoimentos apresentados como reais.

Use conteúdo demonstrativo claramente marcado como placeholder caso não existam avaliações reais.

Visual dos cards:

- avatar circular

- nome

- estrelas

- depoimento

- borda sutil verde

- animação suave de entrada

Deixar fácil substituir posteriormente pelos depoimentos reais.

==================================================

7. FAQ

==================================================

Título:

“AINDA TEM DÚVIDAS?”

Perguntas:

“O que é o Renda Oculta?”

“Preciso ter experiência para começar?”

“Preciso de computador?”

“Posso acessar pelo celular?”

“Como recebo o acesso?”

“É uma promessa de ganho garantido?”

Na última pergunta, responder de maneira transparente:

“Não. O Renda Oculta apresenta estratégias e possibilidades de renda extra. Os resultados dependem da aplicação, dedicação, contexto e outros fatores individuais. Não existe garantia de ganhos.”

==================================================

8. CTA FINAL

==================================================

Criar uma seção final cinematográfica.

Título:

“SEU CELULAR JÁ ESTÁ NAS SUAS MÃOS.”

Subheadline:

“Agora você decide se vai continuar apenas consumindo conteúdo ou começar a descobrir novas possibilidades.”

Botão:

“QUERO DESCOBRIR O RENDA OCULTA”

Adicionar o mockup do ebook ao lado.

==================================================

ANIMAÇÕES E UX

==================================================

Usar animações suaves e premium:

- fade-in ao entrar no viewport

- pequenos movimentos de parallax

- glow verde pulsando muito lentamente

- partículas flutuando

- brilho passando discretamente por alguns elementos

- hover elegante nos botões

- cards subindo levemente no hover

- transições de 200–400ms

- scroll suave

NÃO usar animações exageradas.

NÃO usar efeitos que prejudiquem performance.

Adicionar suporte completo para:

- desktop

- tablet

- celular

A versão mobile deve ser prioridade.

No mobile:

- texto centralizado

- ebook aparecendo logo após a headline

- CTA grande e fácil de tocar

- espaçamento confortável

- nenhuma seção deve ficar horizontalmente quebrada

==================================================

CONVERSÃO

==================================================

Todos os CTAs devem usar exatamente o checkout Kiwify fornecido no briefing.

Os botões devem ter aparência premium:

- verde neon

- texto preto

- sombra/glow verde

- hover com aumento muito sutil

- largura confortável no mobile

Adicionar também um CTA fixo discreto no mobile após o usuário começar a rolar:

“QUERO ACESSAR”

==================================================

SEO

==================================================

Title:

“Renda Oculta | Renda Extra pelo Celular”

Meta description:

“Descubra o método para buscar uma renda extra usando apenas o celular. Aprenda estratégias práticas e comece do zero.”

==================================================

REGRA FINAL DE DESIGN

==================================================

A página precisa parecer uma marca premium de tecnologia financeira, NÃO uma página genérica de ebook.

Priorize:

IMPACTO VISUAL → CLAREZA → DESEJO → CONFIANÇA → CTA.

A primeira dobra precisa fazer o visitante entender em poucos segundos:

1. O que é

2. Qual benefício

3. Que é pelo celular

4. Que existe uma oportunidade

5. Onde clicar
